sheet in a storage-isolated widget-test harness. The harness uses recorded real
public AniList GraphQL responses and downloaded public covers; it loads the
project fonts and themes. These are not mockups, native device screenshots or
certification of source reading/video playback. No personal library, account,
history or desktop capture is included.

English UI, light and dark themes; Manga, Anime, Novel, details and desktop Novel.

Original metadata and cover images remain attributed to AniList and their
respective publishers/artists. These files are review evidence, not bundled app
assets. This media-only branch is separate from the feature PR payload.
